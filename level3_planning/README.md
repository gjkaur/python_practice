## Course Overview

Level 3 is aligned with **PCPP-32-101** (Certified Professional in Python Programming 1) and covers:

- **Section 1**: Advanced Object-Oriented Programming (35%)
- **Section 2**: Coding Conventions & Best Practices (12%)
- **Section 3**: GUI Programming (20%)
- **Section 4**: Network Programming (18%)
- **Section 5**: File Processing & Environment (15%)

## Module Structure

The course is organized into 12 modules over 12 weeks:

1. **M01**: Advanced OOP Foundations (1.1-1.3)
2. **M02**: Magic Methods & Special Methods (1.2)
3. **M03**: Decorators & Extended Arguments (1.4)
4. **M04**: Static/Class Methods & Abstract Classes (1.5-1.6)
5. **M05**: Encapsulation & Built-in Subclassing (1.7-1.8)
6. **M06**: Advanced Exceptions & Object Copying (1.9-1.10)
7. **M07**: Serialization & Metaprogramming (1.11-1.12)
8. **M08**: PEP Standards & Best Practices (2.1-2.3)
9. **M09**: GUI Programming with tkinter (3.1-3.3)
10. **M10**: Network Programming & REST (4.1-4.4)
11. **M11**: Database & File Processing (5.1-5.2)
12. **M12**: Integration & Capstones (All sections)

## Mini Projects

- **MP01**: OOP Class Hierarchy with Magic Methods
- **MP02**: Decorator Library
- **MP03**: Abstract Base Class Framework
- **MP04**: Encapsulated Class Design
- **MP05**: Exception Handling System
- **MP06**: Object Persistence System
- **MP07**: Code Quality Refactor
- **MP08**: GUI Calculator or Todo App
- **MP09**: REST API Client
- **MP10**: Database-Backed Application

## Capstones

- **Capstone 1**: Full-Stack GUI Application with Database
- **Capstone 2**: REST Client with GUI Frontend

## Prerequisites

Students should have completed Level 2 (PCAP) or equivalent knowledge:
- Object-oriented programming basics
- Modules and packages
- Exception handling
- File I/O
- String processing

## Learning Outcomes

Upon completion, students will be able to:

- Design and implement sophisticated OOP solutions using magic methods, decorators, and abstract classes
- Build GUI applications using tkinter with event-driven programming
- Create REST API clients and work with network protocols
- Implement database-backed applications with SQLite
- Write production-quality code following PEP 8, PEP 257, and PEP 484 standards
- Apply advanced Python features (metaclasses, serialization, exception chaining) appropriately
- Integrate multiple technologies (GUI + database + networking) in complete applications

## Assessment

- **Weekly Assignments**: Mini projects (MP01–MP10) aligned with module objectives
- **Mid-Course Practical (Week 6)**: OOP-focused exam covering Sections 1.1–1.10
- **Code Reviews**: Focus on PEP 8/257 compliance, OOP design, error handling
- **Final Capstones (Week 12)**: Two comprehensive projects integrating multiple sections
- **Quizzes**: Conceptual questions mapped to PCPP objectives
