## Concepts & practice

1. Create a virtual environment in a folder, activate it, and run `python --version`.
2. Write a script that prints your name and the current date (as text). Add a one-line comment.
3. Intentionally introduce a syntax error and an indentation error; read the traceback and fix them.
4. From the module: complete at least 5 exercises from the M01 practice set in the module `.md` or `practice/practice_01_*.py`.
