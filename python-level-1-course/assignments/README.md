# Assignments – Level 1 Python Course

This folder contains **weekly assignment sheets** that tie together modules, practice exercises, and mini projects. Use them for homework, in-class practice, or self-study.

---

## How to Use

- **Instructor**: Assign one sheet per week; adjust deadlines to your schedule.
- **Learner**: Work through the "Concepts & Practice" section first, then the "Mini Project" tasks. Submit or demo as required by your instructor.
- **Self-paced**: Follow the week order; each sheet links to the relevant module and project.
