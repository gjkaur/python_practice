# Week 11 Assignment – Database & File Processing

**Module**: M11 – Database & File Processing  
**PCPP Objectives**: 5.1, 5.2  
**Mini Project**: MP10 – Database-Backed Application

## Learning Objectives

- Connect to SQLite databases and perform CRUD operations
- Use transactions for data integrity
- Process CSV files using `csv` module
- Configure and use `logging` module
- Parse configuration files with `ConfigParser`

## Reading

1. Review `modules/M11_Database_File_Processing/M11_Database_File_Processing.md`
2. Study examples
3. Complete practice exercises

## Exercises

### Exercise 1: Database CRUD
Create a database with a `products` table. Implement full CRUD operations.

### Exercise 2: Transactions
Implement a function that updates multiple records in a transaction, rolling back on failure.

### Exercise 3: CSV Import/Export
Create functions to export database data to CSV and import CSV data into database.

### Exercise 4: Logging
Set up logging with file and console handlers, custom formatter.

### Exercise 5: ConfigParser
Create a configuration system reading database and application settings from `.ini` file.
