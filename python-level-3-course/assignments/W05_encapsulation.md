## Exercises

### Exercise 1: Properties
Create a `BankAccount` class with `balance` property (read-only, modified via `deposit()`/`withdraw()` methods).

### Exercise 2: Property with Validation
Create a `Temperature` class with `celsius` property. Setter validates: temperature >= -273.15.

### Exercise 3: Built-in Subclassing
Create a `UniqueList` class inheriting from `list` that prevents duplicate items.

### Exercise 4: Another Built-in Subclass
Create a `CaseInsensitiveDict` class inheriting from `dict` with case-insensitive keys.
