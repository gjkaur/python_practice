# Week 8 Assignment – PEP Standards & Best Practices

**Module**: M08 – PEP Standards & Best Practices  
**PCPP Objectives**: 2.1, 2.2, 2.3  
**Mini Project**: MP07 – Code Quality Refactor

## Learning Objectives

- Understand PEP concepts and Python philosophy
- Apply PEP 8 guidelines comprehensively
- Write proper docstrings (PEP 257)
- Use type hints (PEP 484) effectively
- Use code quality tools

## Reading

1. Review `modules/M08_PEP_Standards/M08_PEP_Standards.md`
2. Run `import this` to see PEP 20
3. Read PEP 8, PEP 257, PEP 484 summaries
4. Complete practice exercises

## Exercises

### Exercise 1: PEP 8 Compliance
Refactor a provided "messy" code file to follow PEP 8. Use `flake8` or `black` to check/format.

### Exercise 2: Docstrings
Add comprehensive docstrings (PEP 257) to all functions and classes in a previous project.

### Exercise 3: Type Hints
Add type hints (PEP 484) to all function signatures in a previous project. Use `mypy` to check.

### Exercise 4: Code Review
Review a classmate's code (or your own previous work) using the code review rubric.

## Mini Project

**MP07 – Code Quality Refactor**: Select a previous project and refactor it to meet all PEP standards.

## Submission

- Refactored code with PEP 8/257/484 compliance
- Documentation of refactoring changes
- MP07: Code quality refactor

## Assessment Criteria

- PEP 8 Compliance (30%), Docstrings (30%), Type Hints (30%), Documentation (10%)
