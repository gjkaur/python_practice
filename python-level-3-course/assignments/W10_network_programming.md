# Week 10 Assignment – Network Programming & REST

**Module**: M10 – Network Programming & REST  
**PCPP Objectives**: 4.1, 4.2, 4.3, 4.4  
**Mini Project**: MP09 – REST API Client

## Learning Objectives

- Understand network programming concepts
- Work with sockets
- Serialize/deserialize JSON and XML
- Build REST API clients using `requests`
- Handle HTTP methods and errors

## Reading

1. Review `modules/M10_Network_Programming/M10_Network_Programming.md`
2. Study examples
3. Complete practice exercises

## Exercises

### Exercise 1: JSON Processing
Create functions to serialize Python objects to JSON file and deserialize back.

### Exercise 2: XML Processing
Parse an XML file and extract specific data using `find()` and `findall()`.

### Exercise 3: REST Client
Create a `RESTClient` class with `get()`, `post()`, `put()`, `delete()` methods.

### Exercise 4: Error Handling
Implement robust error handling for network requests with retries and timeouts.

### Exercise 5: API Integration
Use your REST client to interact with a real API (e.g., JSONPlaceholder).
