# Week 9 Assignment – GUI Programming with tkinter

**Module**: M09 – GUI Programming with tkinter  
**PCPP Objectives**: 3.1, 3.2, 3.3  
**Mini Project**: MP08 – GUI Calculator or Todo App

## Learning Objectives

- Understand GUI concepts and event-driven programming
- Create windows and widgets using tkinter
- Use layout managers effectively
- Handle events and callbacks
- Use observable variables

## Reading

1. Review `modules/M09_GUI_Programming/M09_GUI_Programming.md`
2. Study examples
3. Complete practice exercises

## Exercises

### Exercise 1: Basic Window
Create a window with a label and button. Button shows a messagebox when clicked.

### Exercise 2: Form Layout
Create a form using `grid()` with name, email fields, and submit button.

### Exercise 3: Event Handling
Create an entry field and label. Label updates when Enter is pressed in entry field.

### Exercise 4: Observable Variables
Create two entry fields linked to `StringVar`. A label shows concatenated values automatically.

### Exercise 5: Calculator Layout
Design calculator GUI layout (functionality in MP08).

## Mini Project

**MP08 – GUI Calculator or Todo App**: Implement according to specification.
