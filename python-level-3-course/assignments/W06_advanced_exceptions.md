## Exercises

### Exercise 1: Exception Chaining
Create a custom exception hierarchy. Implement a function that chains exceptions (explicit chaining with `from`).

### Exercise 2: Traceback Analysis
Create a function that catches an exception, extracts traceback information, and formats it for logging.

### Exercise 3: Shallow vs Deep Copy
Create a class with nested mutable attributes. Demonstrate the difference between `copy.copy()` and `copy.deepcopy()`.

### Exercise 4: Custom Copy Methods
Implement `__copy__` and `__deepcopy__` methods for a custom class.
