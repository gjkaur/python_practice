# Week 4 Assignment – Static/Class Methods & Abstract Classes

**Module**: M04 – Static/Class Methods & Abstract Classes  
**PCPP Objectives**: 1.5, 1.6  
**Mini Project**: MP03 – Abstract Base Class Framework

## Learning Objectives

- Design and use `@staticmethod` and `@classmethod`
- Define abstract base classes using `abc` module
- Implement abstract methods
- Use multiple inheritance with abstract classes
- Create factory methods

## Reading

1. Review `modules/M04_Static_Class_Methods/M04_Static_Class_Methods.md`
2. Study examples
3. Complete practice exercises

## Exercises

### Exercise 1: Static Methods
Create a `MathUtils` class with static methods: `add()`, `multiply()`, `power()`.

### Exercise 2: Class Methods
Create a `Date` class with `@classmethod from_string()` alternative constructor.

### Exercise 3: Abstract Base Class
Create an `Animal` abstract class with abstract method `make_sound()`. Create `Dog` and `Cat` implementations.

### Exercise 4: Multiple Inheritance
Create abstract classes `Flyable` and `Swimmable`. Create a `Duck` class inheriting from `Animal`, `Flyable`, and `Swimmable`.
