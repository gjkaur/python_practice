## Learning Objectives

- Integrate multiple technologies (GUI + database + networking)
- Apply architectural patterns (MVC)
- Structure large projects professionally
- Write comprehensive tests
- Create production-ready documentation

## Reading

## Capstone Projects

Complete **both** capstone projects:

### Capstone 1: Full-Stack GUI Application with Database
- GUI application using tkinter
- SQLite database backend
- Proper OOP design
- Error handling and logging
- Configuration management

### Capstone 2: REST Client with GUI Frontend
- REST API client using `requests`
- GUI frontend using tkinter
- JSON/XML processing
- Data persistence
- Error handling and logging

## Requirements

Each capstone must include:

1. **Source Code**: All Python files with proper structure
2. **README.md**: Project description, installation, usage, architecture
3. **Tests**: Unit tests for core functionality
4. **Documentation**: Docstrings for all public APIs
5. **Git History**: Meaningful commit history

- Capstone 2: Complete implementation
