# Level 3 Assignments

Weekly assignments for the Level 3 Professional Python course, aligned with PCPP-32-101.

## Assignment Structure

Each assignment (W01–W12) includes:

- **Learning Objectives**: What you'll learn this week
- **Reading**: Required reading from modules
- **Exercises**: Practice problems aligned with module content
- **Mini Project**: Work on the week's mini project
- **Submission**: What to submit and how
- **Assessment Criteria**: How your work will be evaluated

## Weekly Assignments

- **W01**: Advanced OOP Foundations (M01)
- **W02**: Magic Methods & Special Methods (M02)
- **W03**: Decorators & Extended Arguments (M03)
- **W04**: Static/Class Methods & Abstract Classes (M04)
- **W05**: Encapsulation & Built-in Subclassing (M05)
- **W06**: Advanced Exceptions & Object Copying (M06)
- **W07**: Serialization & Metaprogramming (M07)
- **W08**: PEP Standards & Best Practices (M08)
- **W09**: GUI Programming with tkinter (M09)
- **W10**: Network Programming & REST (M10)
- **W11**: Database & File Processing (M11)
- **W12**: Integration & Capstones (M12)

## Submission Guidelines

- Submit code files with proper naming conventions
- Include docstrings (PEP 257) for all classes and functions
- Add type hints (PEP 484) to function signatures
- Follow PEP 8 style guidelines
- Use Git for version control with meaningful commit messages

## Getting Help

- Review module examples and practice files
- Check the course resources in `resources/`
- Consult the PCPP-32-101 syllabus (`../Level_3.pdf`)
- Ask questions during code reviews
