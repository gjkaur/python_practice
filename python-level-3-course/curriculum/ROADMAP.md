# Level 3 Course Roadmap

## Overview

This 12-week course covers all PCPP-32-101 objectives across 5 major sections:

- **Section 1**: Advanced Object-Oriented Programming (35%, 15 items)
- **Section 2**: Coding Conventions & Best Practices (12%, 7 items)
- **Section 3**: GUI Programming (20%, 8 items)
- **Section 4**: Network Programming (18%, 8 items)
- **Section 5**: File Processing & Environment (15%, 7 items)

## Skills Progression

### Stage 1 – Advanced OOP Mastery (Weeks 1–5)
- Magic methods, inheritance hierarchies, decorators, abstract classes, encapsulation
- Outcome: Design and implement sophisticated OOP solutions

### Stage 2 – Robustness & Metaprogramming (Weeks 6–7)
- Chained exceptions, object copying, serialization, metaclasses
- Outcome: Build robust systems with advanced error handling and persistence

### Stage 3 – Professional Standards (Week 8)
- PEP 8, PEP 257, type hints, code quality tools
- Outcome: Produce code that meets professional Python standards

### Stage 4 – GUI & Network Programming (Weeks 9–10)
- Event-driven programming, tkinter widgets, sockets, REST APIs, JSON/XML
- Outcome: Build interactive applications and integrate with web services

### Stage 5 – Data Persistence & Integration (Weeks 11–12)
- SQLite databases, file formats (CSV, XML), logging, configuration management
- Outcome: Build complete applications with data persistence and professional logging

## Assessment Timeline

- **Weekly**: Mini projects (MP01–MP10) with code reviews
- **Week 6**: Mid-course practical exam (OOP-focused)
- **Week 12**: Final capstones with comprehensive evaluation
- **Throughout**: Quizzes on PCPP concepts
