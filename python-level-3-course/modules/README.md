# Level 3 Modules

This directory contains 12 modules covering all PCPP-32-101 objectives.

## Module Structure

Each module directory contains:

- `M##_Module_Name.md` - Module guide with learning objectives and topics
- `M##_Concepts.ipynb` - Jupyter notebook with concepts and examples (optional)
- `examples/` - Example code demonstrating module concepts
- `practice/` - Practice exercises for students

## Modules

- **M01**: Advanced OOP Foundations (PCPP 1.1, 1.3)
- **M02**: Magic Methods & Special Methods (PCPP 1.2)
- **M03**: Decorators & Extended Arguments (PCPP 1.4)
- **M04**: Static/Class Methods & Abstract Classes (PCPP 1.5, 1.6)
- **M05**: Encapsulation & Built-in Subclassing (PCPP 1.7, 1.8)
- **M06**: Advanced Exceptions & Object Copying (PCPP 1.9, 1.10)
- **M07**: Serialization & Metaprogramming (PCPP 1.11, 1.12)
- **M08**: PEP Standards & Best Practices (PCPP 2.1, 2.2, 2.3)
- **M09**: GUI Programming with tkinter (PCPP 3.1, 3.2, 3.3)
- **M10**: Network Programming & REST (PCPP 4.1, 4.2, 4.3, 4.4)
- **M11**: Database & File Processing (PCPP 5.1, 5.2)
- **M12**: Integration & Capstones (All sections)

## Usage

1. Read the module `.md` file for overview and learning objectives
2. Study the examples in `examples/` directory
3. Complete practice exercises in `practice/` directory
4. Work on the related mini project (see `../projects/`)

## PCPP Alignment

All modules explicitly reference PCPP-32-101 objectives. See `../level3_planning/LEVEL3_PCPP_ALIGNED_PLAN.md` for detailed mapping.
