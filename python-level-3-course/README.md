# Python Level 3 – Professional Course

**Goal**: Build production-ready Python applications with advanced OOP, GUI, networking, and database integration while fully covering the **PCPP-32-101** syllabus (Level_3.pdf) and reinforcing professional practices.

This repository contains the curriculum assets for the **Python Level 3** course:

- **curriculum/** – ROADMAP with week-by-week flow and PCPP section mapping.
- **modules/** – Twelve modules (M01–M12): .md guides, concept notebooks, examples, practice.
- **projects/** – Ten mini projects (mp01–mp10) with READMEs and code.
- **capstones/** – Two capstones (GUI App with Database, REST Client with GUI) with specs and code.
- **assignments/** – Weekly assignment sheets (W01–W12).
- **assessments/** – Midterm and final practical rubrics, code review rubric.
- **resources/** – Teaching notes for delivery and pacing.

## Course Outcomes

By the end of Level 3, learners will be able to:

- **Design sophisticated OOP systems** using magic methods, decorators, abstract classes, and metaprogramming.
- **Build GUI applications** using tkinter with event-driven programming and proper separation of concerns.
- **Create REST API clients** using the `requests` library and handle JSON/XML data exchange.
- **Implement database-backed applications** using SQLite with proper transaction handling and CRUD operations.
- **Write production-quality code** following PEP 8, PEP 257 (docstrings), and PEP 484 (type hints).
- **Apply advanced Python features** including exception chaining, object serialization, and metaclasses appropriately.
- **Integrate multiple technologies** (GUI + database + networking) in complete, maintainable applications.

## Usage

- **Instructor-led**: Use ROADMAP and module .md for session planning; assignments and assessments for grading.
- **Self-paced**: Follow ROADMAP; work through modules in order, then mini projects and capstones.
- **Alignment**: All content is aligned with Level_3.pdf (PCPP-32-101). The Cursor rule `.cursor/rules/pcpp-level3-syllabus-alignment.mdc` keeps edits aligned with the syllabus.

## Principles

- **PCPP coverage**: Every objective and sub-bullet from Level_3.pdf is covered; see the plan's complete topic list and module-to-objective mapping.
- **Professional focus**: Advanced OOP, GUI development, network programming, database integration, code quality standards.
- **Integration emphasis**: Capstones require combining multiple technologies and concepts.
- **Bridge beyond**: Prepares for advanced frameworks, testing, deployment, and architecture (Level 4/PCPP2).

## Prerequisites

Students should have completed Level 2 (PCAP) or equivalent knowledge:
- Object-oriented programming basics
- Modules and packages
- Exception handling
- File I/O
- String processing

For the detailed roadmap, see `curriculum/ROADMAP.md`.
